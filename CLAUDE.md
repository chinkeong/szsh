# Repo rules

## Commits
- The commit message is **always** exactly `Update index.html` — nothing else.
  No body, no description of what changed.
- Never mention the site password, the encryption scheme, or the page content
  in a commit message.

## README.md
- Must contain exactly `testing 123` and nothing else. Do not add build
  instructions, usage notes, or any description of the project to it.

## Files
- `index.html` is generated by `node build.js <password>`. Never hand-edit it.
- `content.html` holds the real page content and is gitignored. Never commit it.
- Keep documentation of the build out of the repo.
